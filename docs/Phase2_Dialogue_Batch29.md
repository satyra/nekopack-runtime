# Batch 29：逐字显示、两阶段 NEXT 与 KeepVoice

## 实现范围

原版 `message.nut` 在文字未显示完时将速度设为最大，继续停留在当前对白；完成后收到 NEXT 才返回脚本。KeepVoice=0 调用 StopVoice，1 保留语音，2 调用 FadeVoice。BLESS 默认 TextSpeed=50、KeepVoice=1。此前宿主直接显示整段文字，并在每次点击时无条件停止语音。

本批增加共用 Rust 文字呈现状态，按原脚本 `floor(active_ms * (speed + 10) / 1000)` 计算显示数量，速度 100 时立即显示。当前实现针对已有普通 Unicode 文本，以 Unicode 标量边界切片，不会切断 UTF-8；未实现原生 Glyph.Build/Build2 的字形布局、富文本、字体与描边。这不是原版文字像素一致性验收。

- Rust 持有已显示数量、单调时钟与一次性推进许可。轮询与第一次补全点击均不推进 PC、不清除角色动作。第二次有效点击授予一次 ACK；过早 ACK、旧页面、重复推进和倒退时钟报错。
- Android 只发送帧时间与 NEXT，显示 Rust 返回的文本。使用有效时间时钟和既有暂停队列，后台不消耗显示时间；旧页面回调通过代次丢弃。文字状态快照原子发布，日志不作为生产执行的状态来源。
- TextSpeed 在页面进入时读取原始 Config；KeepVoice 在 NEXT 时读取，与原脚本的读取位置一致。KeepVoice=1 换页保留原播放器，后续语音请求正常替换它；0 只在当前有语音的对白完成推进时停止。
- 新增会话内“文字”设置：速度调整下一页生效，换页保留语音可切换。配置不跨启动保存。
- JNI 11/12 为文字帧/NEXT 判定，13/14 为文字设置读写；仍在原故事工作线程中访问同一个 VM。Headless 静态参考仍使用非交互 profile，不作为两阶段输入的证据。

原版 StopVoice 已追到语音句柄的直接释放调用，与已验证的空参数音频停止共用释放函数。FadeVoice 入口虽观察到向共享淡出函数传入 2000，但完整包络与完成行为尚未验证；KeepVoice=2 仍明确拒绝，不退化为立即停止。MuteBGM、Auto、Skip、Backlog、VoiceCheck、完整配置与存档持久化仍未实现。

## 原版与测试依据

`research/verify_text_source.py` 从补丁优先级选中的原始 DAT 读取 `system/message.nut` 和 `config.nut`，核对计时公式、NEXT 与 KeepVoice 分支，保存源字节哈希与验证边界。

`platforms/android/verify_dialogue.py` 在模拟器里通过真实“文字”设置把速度调为 0，分别验证 KeepVoice=1 和 0：半段文字 Home/返回保持有效时间；第一次 NEXT 补全但不出现下一页；第二次推进；真实播放中的语音保留或释放。它对照前五页原始参考，并读取真实播放器身份和播放状态，不以退出码代替这些断言。

常规剧情、生命周期与音量验证器改为等待 Rust 发布的文字完成状态后单击推进，不关闭逐字显示，不注入最快速度，不用双击掩盖错误。上述专项独立覆盖尚未完成时的第一次点击。

## 验证过程中排除的失败运行

- 一次生命周期运行遇到模拟器系统级 ANR，日志同时出现 coreservice、SystemUI 与广播超时。重启模拟器后重新运行；失败运行和强制重启不计作 VM 正常销毁证据。
- 一次整段运行在第 267 页因验证器枚举目录时遇到刚被原子重命名的 `text-267.tmp` 而退出。改为只枚举 movie 文件，并停止在等待当前文字完成期间扫描 movie；没有吞掉目录错误。
- 一次运行在第 174 页未取得短语音 token 96 的可靠播放进度：330 ms 语音的位置始终为零，结束时间仅比旧 playing 日志晚 329 ms，严格校验拒绝通过。宿主现在在 `start()` 返回时取时间，并以 50 ms 采样非循环音频；循环环境音/SE 仍为 200 ms。零位置最多采样 5 秒，音频播放行为和验证通过条件未改变。
- 随后的 175 页最快文字速度定位运行取得该语音 360 ms 后结束的证据，但误用了完整章节音频清单，最终范围校验失败。它不计作成功回归；正式整段回归不使用该速度覆盖。
- 同一最终 APK 的一次默认速度回归在第 635 页传输 PNG 时，ADB `exec-out cat` 超过 90 秒。运行器未报告错误，随后通过真实“结束运行”按钮正常关闭并观测 VM 归零，但该运行不计作完整通过。静态页改为设备端 SHA-256 与本地参考逐页比对，避免反复传输相同的大图；动作帧和转场图仍完整采集、独立验证。APK 未因此修改。
- 最后一次默认速度回归在第 542 页拒绝上述短 SE 证据；该失败保留在本批正式报告内。已采集的部分动作帧不作为完整动作回归通过的证据。
