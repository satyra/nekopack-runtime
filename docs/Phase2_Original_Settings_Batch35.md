# Batch 35：原版设置素材页与运行时配置

从标题的 Config 入口打开原版设置素材页，五页可切换。此次接通 **TextSpeed、KeepVoice、VolBGM、VolVO、VolSE、VolENV、VolSYS**，即文字速度、语音保留和五路音量。其他控件只显示当前值，触摸时提示尚未接入；底部持续标明范围。没有把整个原版配置系统标记为完成。

## 实现与原版依据

- `config.nut::ViewConfigPage` 确定公共背景、各页背景及控件字段；`gui.nut::VolumeBar` 确定滑块绘制偏移为轨道宽度乘当前值再除以最大值，左右端按钮分别设置最小/最大值。页面滚动条覆盖五页。
- Rust `settings.rs` 从原始 DAT 读取 `config.mng` 和当前 `configN.mng`，加载有预算限制的 PNG 图层，按原始坐标合成。支持有空格和无空格的 sprite 前缀。第五页包含重复 sprite 名，采用与现有 `DatResources::Assets` 一致的后项覆盖规则，替换时扣除旧图像的驻留内存。
- 触点映射仍由 Android 完成，命中、数值范围、滑动捕获、单选和页码由 Rust 判断。滑动超出轨道时数值限制到 0..100，这是当前移动端输入规则，不宣称已逐项验证原版鼠标拖出轨道的行为。
- 设置界面是已观察配置的展示/输入适配器，不执行原版完整 modal GUI 循环。标题 Machine 仍保留待处理 `.map`，设置读写同一个 SystemVm 的 `Config`。返回标题再开始游戏时，将这些对象继续交给现有 StorySession。
- 音量写回后调用原游戏 `RestoreVolume`。进入剧情时，现有 Android 音频和文字控制器读取同一份配置；从这一路进入剧情后，已有宿主音量/文字面板的修改也会保存。
- 返回标题和恢复默认使用宿主按钮。恢复默认只处理本批七项，并从当前游戏 `ConfigDefault` 取值，不重置尚未支持的选项。连续提交时暂时禁用按钮，避免重复返回造成失效会话调用。

## 配置持久化

Rust `preferences.rs` 定义固定 12 字节的运行器格式：`NKCF`、版本字节 `1`，然后依次为 TextSpeed、KeepVoice、VolBGM、VolVO、VolSE、VolENV、VolSYS 七个无符号字节。KeepVoice 只能为 0/1，其余范围为 0..100。导入先验证魔数、版本、精确长度和全部取值，再修改 VM；错误显式返回。

Android 以 Base64 保存该载荷，使用应用私有 SharedPreferences 的同步提交，按 SAF 目录 URI 和游戏编号区分。下次正常启动在显示标题前导入，原始 DAT 和游戏目录不写入配置文件。格式本身不依赖 Android；宿主负责存储位置。

这**不是原版 `config.sav` 兼容实现，也不是剧情存档**。没有序列化调用栈、PC、场景、音频播放位置或变量存档。直接 `story_game` 的自动回归入口继续使用独立默认配置，不读写用户持久化设置，以保留原有验证口径。

## 实测证据

`platforms/android/verify_settings.py` 使用普通 ADB，在 PGKM10 / Android 15 / aarch64 / native bridge 0 上执行；属于原生 ARM64，不是 libnb 翻译执行。

- 音量页使用独立 Python 原始 PNG 合成，与 Rust 输出逐像素一致；这不是原版 Windows 动态截图完全一致的证明。
- 五页切换成功；未支持的屏幕选项不会改变配置；实际 DOWN/MOVE/UP 拖动 BGM 滑条成功。
- 修改为文字速度 0、语音保留 0，BGM/语音/SE/ENV/SYS 分别为 23/61/17/33/44。后台恢复、返回标题并关闭、重新启动后均保留这些值。
- 从标题进入前五页剧情，完整页面元数据和场景 PNG 与既有基线一致。音频控制器收到全部五路值，文字控制器收到速度和保留设置；实际语音播放器增益为 0.61，推进第四页时停止仍在播放的语音。未宣称在这五页中分别播放并测量了全部五种音频。
- 恢复七项游戏默认值，关闭并再次启动后仍为默认值。测试结束恢复默认配置；各次明确关闭后的 VM 追踪存活字节为零。
- Rust 单元测试覆盖格式版本/截断/超长/范围、验证失败不修改 VM、配置导入导出和游戏默认值恢复，以及轨道取值与 sprite 名规范化。全工作区 134 个顶层测试、7 次隔离原生安全探针、Clippy 严格检查、17 个 Python 验证器测试及 NDK ARM64 构建通过。

设备细节、APK 哈希及结果见 `research/settings-batch35-phone.json`；构建与检查摘要见 `research/settings-batch35-checks.json`。同批 `title` 和 `dialogue` 报告记录既有标题/对白回归，不能等同本批新功能之外的全篇通关。
