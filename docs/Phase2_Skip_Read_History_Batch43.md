# Batch 43：对白快进与跨会话已读记录

## 已确认的原版脚本行为

依据 BLESS DAT 的 `system/message.nut`、`system/config.nut`、`system/system.nut`：

- `SkipNoRead=0` 是默认值。未读检查位于进入对白时；未读页会取消快进。
- 在已经显示的未读页上开启快进，会先推进当前页，再在下一页未读处停止。不能把入页检查错误地移到开关处理，导致当前页也无法快进。
- 入页时处于快进则全文显示，并且不启动该页语音；循环中的 NEXT 不等待 AutoSpeed 或语音结束。在已开始的对白中开启快进，先补全文字，再推进；已播放语音仍服从原有 KeepVoice。
- 普通 NEXT 会取消快进。通过系统菜单进入设置等界面也会取消快进。
- ReadedFast 仅使已读正文瞬间显示，不自动换页；它与快进、自动播放是三个不同概念。
- MegaSkip 的相关入口／执行路径在所读脚本中被注释，没有启用这段代码。

本批是原始系统脚本的语义确认，没有声称完成 Windows 原版可执行文件的对照计时。原生 SwitchSkip 的内部实现、Ctrl 按住快进、IsReaded 的原版写入时点和原版存储布局仍未确认。

## 实现与边界

StorySession 持有快进状态，沿用现有页面 token、逐字状态和单次 ACK。入页检查在 Speaker 的语音请求之前执行；Machine 只检查当前文本或紧邻 Speaker 的下一文本，不跨命令查找，不执行脚本。未知指令、执行预算和宿主效果 ACK 均保留原路径，没有通过批量推进绕过等待请求。

Android 新增明确的快进开关；关闭操作可在已有推进请求或效果期间排队处理，至多完成已授予的当前页推进，不继续跳过后续页。自动与快进在宿主开关上采用互斥策略，避免两种推进条件竞争；这是当前运行器接口约定，未冒充已反编译验证的原生 SwitchSkip 内部逻辑。

本批实现对白快进，不擅自缩短尚未确认快进语义的 wipe、角色动作、等待或 movie。movie 保留独立的播放／结束／跳过 ACK。选择肢的 KeepSkip、原版快捷图标及键盘按住操作仍不属于本批已完成能力。ReadedFast 的核心语义有测试，但原版当前所见设置页没有对应绑定，因此没有新增虚构控件。

原版设置第一页的 SkipNoRead 单选项已接入共用配置。NKCF 升至 v6（27 字节），继续读 v1～v5；旧格式保留新字段的当前／默认值。默认仅跳过已读，允许跳过未读是用户明确选择的配置。

## 已读记录契约

新增跨平台 NKRD v1；不是原版存档格式。键为脚本名称、物理行号和精确 UTF-8 正文，不使用会碰撞的短哈希。这里的物理行号是当前运行器的文本请求位置，不声称等同原版 ScriptPage 编号。正文、位置或脚本名变化会变为未读；不保证整包修订或上下文改变但三者完全相同时自动失效。Android 按 SAF tree 和游戏序号隔离记录。

仅在 Rust 授予离开当前对白的许可时记录已读；仅显示、轮询、打开设置、启动语音或关闭当前未推进页面不会标记。Android 在传递推进许可给 UI、发送 ACK 之前持久化，因此下一条未知命令导致会话停止也不丢失已完成对白。该明确的运行器时点不等于已确认原生 IsReaded 的写入时点。

记录限制为 8 MiB 载荷、100000 条、单键 64 KiB。输入版本、长度、结构和重复条目均校验，解析完成后才替换现有集合；越界直接报错，不清空或静默丢弃既有已读数据。导入仅允许新会话，运行中不能替换已读集合。

## 验证方法

核心测试覆盖未知页边界、当前未读开启快进、允许跳过未读、过期 token、跨会话恢复、正文／位置身份变化、重复／截断载荷、ReadedFast 不推进和下一已读页语音抑制。

`verify_story_settings.py --skip-check --auto-check` 使用 BLESS 原始 DAT/SAF、真实标题入口。快进专项使用独立的随机已读测试配置名；通过正常执行实际读完前 5 页后重启，没有注入伪造已读键。验证第 6 页停止、已读语音不启动、允许跳过未读、手动取消、配置重启恢复。随后继续 57 页基线、原版设置／后台／BGM／角色动作及 55 次自动播放回归。

本批仅 emulator-5568（x86_64 / libnb.so）ARM64 翻译执行，不是真机结论。没有读取 CG／回想详细内容，游戏资源和设备已读正文不提交仓库。
