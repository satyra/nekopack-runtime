# Batch 39：剧情内原版设置与原对白恢复

## 实现

Android 剧情控件增加“原版设置”。入口只在有效对白帧可操作时启用；转场、视频及已经发出换页请求的阶段不开放。设置仍使用共用 Rust `Settings`，原始 DAT 素材和相同 `Config`，没有创建第二个 VM 或从章节起点重放。

`StorySession` 保留 Machine、调用栈、当前 Page、Reveal、动作队列和音频请求状态。打开前校验对白 token、等待请求及推进状态；设置期间拒绝正文推进和角色帧推进，cached poll 仍返回原待处理事件。设置包提供实际正文 token、可见字符数、正文时钟、动作时钟及执行步数，供回归核对。

Android 在打开时冻结剧情 ActiveClock 并暂停音频/动画；设置界面使用独立 UI 调度队列，避免暂停剧情时把设置本身也锁住。切后台再回来时，只恢复设置界面，剧情保持暂停。返回后重新应用音量、恢复同一个播放器及动作调度。这个暂停策略是当前 Android 宿主的明确行为，不宣称本批逐项比对了原版 Windows 设置期间的音频策略。

对白呈现使用代次隔离打开前的异步回包，返回时继续同一个 token 和开始时间，不调用 `show()` 重置文字。TextSpeed 保持已有的下一页生效规则；KeepVoice 在换页时读取；BoxOpacity 在返回时从原始 msgbox PNG 重建背景框，再按当前已显示字符数渲染，不对已经变淡的图层重复乘透明度。标题与剧情复用相同设置持久化格式。

快捷键弹窗的“取消选择”只退出弹窗；普通设置返回按钮在剧情中显示“返回剧情”。设置页中仍未接通的选项和静态示例预览边界保持不变。本批是宿主入口接通，不是完整原版侧边快捷图标或键盘分发实现。

## 验证

使用 emulator-5568：x86_64 + libnb.so 翻译执行 ARM64 APK，未使用真机。验证从 SAF 原始 DAT 和真实标题入口进入 BLESS，不使用解包 fixture 替代执行。只检查普通剧情与设置；未进入 CG 或回想页面。

验证器 `platforms/android/verify_story_settings.py` 的探针只在指定对白已有可见字符后调用同一个“原版设置”按钮，便于稳定覆盖未完成文字和 250ms 短动作；不跳过脚本、不调整动作时长。设置前后缓存事件的字节一致性由宿主断言，设备测试另外检查时钟、字段、播放状态和后续剧情基线。

结果见 `research/story-settings-batch39-emulator.json` 与同批 `checks` 文件。

验证过程：首轮在读取场景 PNG 时发生一次 ADB 只读传输超时，应用仍在前台且没有运行错误。验证器对只读文件传输增加一次限次重试，动作命令不自动重放。另一轮在到达运动段落前主动停止，用于加强探针：从零字符暂停改成已有可见字符后暂停，并要求动作时钟大于零，避免“重置到零字符也能通过”的薄弱断言。失败及主动停止日志均保留在本地，最终结果只采用完整完成的运行。

返回顺序审查另修正了一项问题：原先配置刷新排在暂停的剧情队列里，播放器可能先按旧音量恢复。现在在设置 UI 队列先应用音量，再恢复剧情时钟和播放器；回归直接检查播放器 `resuming` 快照中的语音增益已为 0。一次加强测试重启时发现先前中止留下了瞬显文字配置，部分文字断言正确失败；已使用此前验证的配置通过实际 UI 恢复后重跑，并为验证器增加初始配置前提检查。没有将这些未完成运行计为通过。

最后一次验证器问题是读取下一页文件早于生成，已修正该等待条件，不改变运行时行为。最终整轮从头完成，没有 UI 抓取或 ADB 读取重试。为缩短无关等待，最终回归通过视频自身的“返回剧情”按钮离开片头，再沿真实章节链路继续；没有跳改 PC 或加载人工章节快照。

## 最终结果

- 第 1 页在显示 7 个字符、正文时钟 129ms 时进入设置；返回后仍为同一 token，205ms / 12 个字符，未回退、未换页，设置停留时间被排除。修改透明度后当前框生效，TextSpeed=100 在下一页的 0ms 帧完成显示。
- 修改、快捷键弹窗取消、五页设置导航、后台停留、再次打开设置及恢复原配置通过。恢复原透明度后当前对白框重新可见。
- 语音静音增益在恢复播放器前已为 0。BGM 暂停位置稳定，返回后同一个播放器和资源 token 继续；不宣称此次额外验证了人的听觉效果。
- 第 56 页在动作时钟 21ms、正文已显示 6 个字符时打开设置，后台返回仍保持状态；关闭设置后动作完成，继续至第 57 页。57 页元数据与场景 PNG 均符合既有基线。
- 正常关闭及设置页内通过宿主退出均通过 native close 检查，VM 追踪存活字节为 0。当前宿主 Android 返回键仍是退出应用；返回对白使用明确的“返回剧情”按钮。
- 工作区 137 个顶层 Rust 测试、7 次隔离原生安全探针、Clippy 严格检查、17 个 Python 测试及 NDK r27d ARM64 构建通过。

这不是全篇通关，也不开放转场或视频中的设置入口。本批未变更配置文件版本、脚本格式、存档语义或 CG/回想功能。
